## Как поддерживать порядок

В roadmap остаётся только незавершённое. После реализации убрать задачу, обновить контракт в архитектуре и постоянные тесты. Не создавать ещё один полный аудит для записи исправления нескольких пунктов.

Повторные отчёты о состоянии до исправлений и статические инвентари удалены. Актуальные размеры и загрузочные связи получают через `scripts/check-module-boundaries.js`, `scripts/check-dependency-contracts.js` и GitNexus. Локальные логи принадлежат игнорируемому `test-results/`; старый repro, ожидающий дефект, не является тестом исправленной версии.
