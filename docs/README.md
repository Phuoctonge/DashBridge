   lifecycle, границы доверия и причины нестандартных механизмов.

   контракта.

## Что хранится в Git

В `docs/` отслеживаются только 11 основных документов, явно разрешённых в
[.gitignore](../.gitignore). Новый документ требует осознанного добавления
в этот список. Устойчивый контракт сначала дополняет существующее профильное
руководство; новая задача — roadmap.

Временные планы, исходные specs, аудиты и хронологические журналы приёмки
сняты с отслеживания. Прежние версии доступны в истории Git; локальные копии
могут оставаться на машине и игнорируются. Не ссылаться на них из основных
документов. Новые черновики хранить в `.dashbridge-local/`, evidence и логи —
в `test-results/`. Не обходить правила через `git add -f`.

Описание изменений выпусков на русском находится в
[GitHub Releases](https://github.com/Phuoctonge/DashBridge/releases).
Перечень проверок не является заявлением об их успешном прохождении: результат
каждого нового прогона фиксируется отдельно с версией и окружением.
